# Core

Pure stress and limit-load functions. No dataclasses, no state — everything is a function call on floats.

Submodules:

- [cylindrical_vessel](core/cylindrical_vessel.md) — Lamé stresses and Von Mises burst pressure for thick-walled cylinders.
- [flat_plate](core/flat_plate.md) — Membrane stress and burst pressure for circular flat plates.
- [bolted_joint](core/bolted_joint.md) — Shear, bearing, tear-out, and net-section stresses and limit loads.
